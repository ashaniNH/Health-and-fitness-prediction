# Health-and-fitness-prediction

Predictive Health Classification Using Fitness Data

This project builds a predictive health classification system using real-world health and fitness tracking data from 3,000 participants collected via wearable devices and activity logs. The dataset includes demographic information, daily activity patterns, and key health indicators such as BMI, heart rate, blood pressure, sleep hours, stress level, hydration, and lifestyle factors like smoking status and activity type. The goal is to classify each individual’s health status (healthy, high blood pressure, diabetes, asthma, etc.) based on these features and support early risk detection and preventive healthcare. 

The workflow covers data preprocessing (type conversion, handling missing values, feature engineering such as BMI, and train–test splitting), descriptive analysis (distribution of health conditions, effects of weight, height, and gender on health, correlation and Cramér’s V heatmaps, FAMD-based exploratory analysis, and multivariate outlier detection), and advanced modeling. Several machine learning algorithms are trained and compared, including Logistic Regression, Ridge Classifier, Linear Discriminant Analysis (LDA), XGBoost, Support Vector Machine (SVM), and Random Forest, using metrics such as accuracy, sensitivity, and F1-score on both training and test sets. 
While tree-based and SVM models achieve very high training accuracy, they exhibit strong overfitting and weaker test performance. Logistic Regression provides the best balance between training (accuracy ≈ 0.713) and testing (accuracy ≈ 0.712) performance, showing strong generalization and clear interpretability for multiclass health prediction. Feature importance analysis highlights the influence of activity patterns, intensity levels, weight, and BMI on health outcomes, demonstrating how wearable and lifestyle data can be leveraged for personalized health monitoring and decision support.
